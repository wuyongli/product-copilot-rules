## Stage To Docs

```md
Stage 0 -> 当前初步判断
Stage 1 -> 当前目标 / 待确认事项
Stage 2 -> 当前目标 / 当前初步判断 / 影响范围与数据判断（初步）
关键取舍过程 -> decision-log.md
稳定结论 -> plan.md 的核心决策与原因
Stage 3 -> 当前系统现状评估 / 影响范围与数据判断（取证后正式结论）
Stage 4 -> 正式版 plan 的需求与范围章节
Stage 4.5 -> 正式版 plan 的开发方案 / 数据影响说明 / 上线方案
```
